# กล้วยตากคุณย่า · บัญชีรายรับ–รายจ่าย

เว็บแอปบันทึกรายรับ–รายจ่าย รายการสินค้า รูปใบเสร็จ/สลิป (มีลายน้ำเลขหลักฐาน) และประมาณการภาษี

- เปิดใช้งาน: https://wongjinda.github.io/kluaytak-khunya/
- ข้อมูลเก็บใน Supabase (โปรเจกต์ `kluaytak-khunya`) ผ่านฟังก์ชัน `public.app_*` ที่ตรวจสิทธิ์ผู้ใช้ทุกครั้ง
- เข้าสู่ระบบด้วยอีเมล เฉพาะอีเมลที่เจ้าของเพิ่มไว้ในหน้า "สำรอง" → "ผู้ใช้งาน"
- คีย์ในไฟล์เป็น publishable key ของ Supabase ซึ่งเปิดเผยได้ ข้อมูลถูกป้องกันด้วยสิทธิ์ในฐานข้อมูล
